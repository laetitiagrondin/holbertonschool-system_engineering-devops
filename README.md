# System Engineering & DevOps

This repository contains projects related to system engineering and DevOps. The main focus is the design, analysis and evolution of web infrastructures.

## Projects

### Web Infrastructure Design

This project covers the design of web insfrastructures hosting the website **www.foobar.com**, starting from a simple single-server arrchitecture and evolving into distributed, secured, monitored and scalable systems.

## Topics covered

- What is a server
- DNS and domain name configuration
- Web server (Nginx)
- Application server
- Database systems (MySQL)
- Load balancing (HAProxy)
- High availability architectures
- Database replication (Primary-Replica)
- Security (firewalls, HTTPS/SSL)
- Monitoring systems and observability
- Scalability and performance improvements
- Single Point of Failure (SPOF) analysis
